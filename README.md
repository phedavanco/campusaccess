# 🎓 CampusAccess — Sistema de Controle de Acesso Acadêmico

Projeto acadêmico desenvolvido durante o curso de Análise e Desenvolvimento de Sistemas na Faculdade Anhanguera.

## Sobre o projeto

O CampusAccess é um protótipo web interativo que simula o gerenciamento de acesso de alunos, professores e funcionários a uma instituição de ensino por meio de catracas eletrônicas.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage para armazenamento de dados demonstrativos

## Funcionalidades

- Login demonstrativo por perfil de usuário
- Painel com indicadores de acessos
- Cadastro, ativação e bloqueio de usuários
- Simulação de entrada e saída por catracas
- Histórico de acessos autorizados e negados
- Filtros de pesquisa e exportação em CSV
- Monitoramento simulado das catracas

## Demonstração online

Acesse o sistema:

https://phedavanco.github.io/campusaccess/

## Observação

Este é um protótipo acadêmico para fins educacionais. Utiliza dados simulados, não possui autenticação de produção nem integração com equipamentos físicos.

## Objetivo

Aplicar conhecimentos de desenvolvimento web, lógica de programação, interfaces e modelagem de sistemas em um projeto prático.
